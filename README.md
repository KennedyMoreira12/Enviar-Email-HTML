# ✉️ Enviar E-mail — HTML

Página de **formulário de contato em HTML/CSS** integrada ao serviço **FormSubmit**, que envia as mensagens diretamente para o e-mail configurado.

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)

---

## ✨ Funcionalidades

- Formulário com campos de **nome**, **e-mail** e **mensagem**
- Envio de e-mail via [FormSubmit](https://formsubmit.co/) (`formaction`)
- Proteção contra spam com campo **honeypot**
- Validação nativa com `required`

## 🚀 Como executar

Abra o `index.html` no navegador, preencha o formulário e envie. Para usar com seu próprio e-mail, altere o atributo `action` do formulário para `https://formsubmit.co/seu-email@exemplo.com`.
